# Scientific Platform - Login & Register Frontend

A modern, responsive, high-aesthetic **React + Vite** frontend for the **Scientific Collaboration Platform** authentication flow, created based on Figma design specifications.

## 🚀 Features

- 🎨 **Figma Design Fidelity**: Built with modern Tailwind CSS v4 and Google Fonts (*Inter*, *Poppins*).
- 🌓 **Dark & Light Mode**: Seamless dark mode support with color theme tokens.
- 👥 **Role Selection**: Dual role-based access for *Researcher*, *Institution Admin*, *Reviewer*, and *System Admin*.
- 🔑 **Login & Register Views**: Tabbed navigation between Sign In, Registration, and Forgot Password reset flows.
- 👁️ **Password Eye Toggle**: Toggle password visibility with icon indicators.
- ⚡ **Vite 6 + React 19**: Lightning-fast hot module replacement (HMR) and optimized build output.

## 🛠️ Getting Started

### Prerequisites

- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Clone or navigate into the directory
cd scientific-auth-app

# Install dependencies
npm install
```

### Development Server

Run the development server locally:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
